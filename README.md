# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズ株式会社のコーポレートサイトです。
クラウド基盤構築、業務システム開発、AI・新規事業開発支援までを一気通貫で手がけるソフトウェア開発会社として、事業内容や会社概要を紹介しています。

## ブラウザでの開き方

1. 本リポジトリをクローンまたはダウンロードします。
2. `skyline-technologies.html` をブラウザ（Chrome、Edge、Safari など）にドラッグ＆ドロップするか、ブラウザのメニューから「ファイルを開く」で選択します。
3. もしくはターミナルから以下を実行します。

   ```bash
   start skyline-technologies.html   # Windows
   open skyline-technologies.html    # macOS
   ```

サーバー不要の静的HTMLファイルのため、上記の方法でそのまま閲覧できます。
